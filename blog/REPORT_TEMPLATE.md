# 研究报告模板

每个报告页面放在 `blog/posts/<slug>/index.html`，并在 `blog/posts.json` 中登记一条元数据。

页面顶部导航固定为：左侧当前报告名称，右侧 `Homepage` 与 `Research Blog`。报告页从 `blog/posts/<slug>/` 出发时，链接分别使用 `../../../` 和 `../../`；移动端隐藏 `Homepage`，保留 `Research Blog`。

报告内容统一使用以下顺序：研究范围与纳入标准、术语和统一视角、方法演化、方法族总结、逐篇论文卡片、跨论文比较、实践建议、开放问题和证据边界。

论文卡片至少包含：首发时间、发表状态、会议或期刊、arXiv 链接、方法族、核心问题、具体方法、实验设置与结果、局限。每张卡片只显示一个时间标签；会议、Findings 和 Workshop 作为独立 venue 标签。
